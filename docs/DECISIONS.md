# Technical decisions

1. **Codex limits:** Use the installed App Server `account/read` and `account/rateLimits/read` protocol. Display the actual plan and usage windows reported by the signed-in account; never fabricate a five-hour limit or translate plan codes.
2. **Refresh cadence:** Cache a versioned quota snapshot on the desktop. Device pulses default to 30 seconds on USB and 60 seconds on battery; App Server refresh is independent at 300 seconds or on a rate-limit update notification.
3. **Audio:** Optional API-key configuration enables `gpt-4o-mini-transcribe` for short WAV requests and `gpt-4o-mini-tts` with Cedar for spoken replies. These API calls may be billed. Fall back to local Windows recognition and System.Speech. Normalize API WAV streaming headers before device playback. No API key is embedded on the device.
4. **Voice permissions:** Local routes and approved project reads remain read-only. Optional ChatGPT plan conversation receives no action tools. Unknown speech gets a capabilities response until account and model selection.
5. **LAN security:** Bind to the desktop's private IPv4 address and authenticate both routes with a random device token. Keep private files out of Git. No internet-facing deployment or port forwarding.
6. **Toolchain:** Support an Arduino CLI executable in `tools/` or on `PATH` with the official M5Stack board package plus M5Unified/M5GFX. Keep build artifacts ignored by Git.
7. **Windows lifetime:** Tkinter is a control panel. An independent per-user service host owns and restarts the backend, can start at Windows sign-in, and persists when the window closes. Control commands use a loopback capability. Device telemetry rides on the existing authenticated pulse.
8. **Conversation:** OpenAI's separate Sign in with ChatGPT OAuth flow is implemented as an opt-in provider. A live consent/model test is still needed. It never uses Codex's stored sign-in or falls back to billed text API inference.
9. **Gmail:** Start with `gmail.metadata` via separate Google Desktop OAuth and independent cached polling. Do not request bodies, search, sending or modification with this first scope. Keep metadata replies on local Windows speech. Google verification and user consent may be required.
10. **Remote gate:** The trusted-LAN HTTP link is insufficient for Android/Tailscale expansion with email or powerful Codex actions. Review encryption, authentication, permissions and device loss before enabling remote access.
